**Context:** Phase 09 moved Do session storage from `~/.consilium/do_sessions/` (global) to `{workDir}/.consilium/sessions/do/` (workspace-local) in the Python CLI codebase (`kimi_cli_mod`). The extension fix must account for both old and new paths.

---

## Root Cause (Unchanged)

`GetAllConsiliumSessions()` handler (lines 96–135 in `session.handler.ts`) has exactly two scan paths:

1. **SDK `listSessions()`** — iterates all registered work dirs, queries CLI for sessions
2. **`listThinkSessions()`** — scans `~/.consilium/think_sessions/{uuid}.jsonl` locally

There is **no scan path for Do sessions** (either local or CLI-based). The `SessionInfo` type already has `isThinking: boolean` so the UI can distinguish Do sessions; only the scan is missing.

---

## Updated Storage Layout (After Phase 09)

| Session Type | Old Path (Pre-Phase 09) | New Path (Post-Phase 09) |
|---|---|---|
| **Think** | `~/.consilium/think_sessions/{uuid}.jsonl` | `{workDir}/.consilium/sessions/think/{uuid}.jsonl` |
| **Do** | `~/.consilium/do_sessions/{uuid}/journal.jsonl` | `{workDir}/.consilium/sessions/do/{uuid}/journal.jsonl` |
| **Regular** | `~/.consilium/sessions/{hash}/wire.jsonl` | `{workDir}/.consilium/sessions/regular/{hash or uuid}/wire.jsonl` |

**Important:** Sessions created before Phase 09 may still exist at the old global paths. The fix must scan **both** old and new locations for backward compatibility.

### Change 3: Add `listDoSessions()` helper

Insert after `listThinkSessions()` (after line 82). This scans **both** old global and new workspace-local paths:

```typescript
async function listDoSessions(registeredWorkDirs: string[]): Promise<SessionInfo[]> {
  const sessions: SessionInfo[] = [];
  const seen = new Set<string>();

  // Helper: scan a directory for Do session subdirs
  async function scanDir(baseDir: string, labelPrefix: string): Promise<void> {
    if (!fs.existsSync(baseDir)) return;
    const entries = await fs.promises.readdir(baseDir, { withFileTypes: true });
    for (const e of entries) {
      if (!e.isDirectory()) continue;
      if (!UUID_REGEX.test(e.name)) continue;
      if (seen.has(e.name)) continue;
      seen.add(e.name);

      const journalPath = path.join(baseDir, e.name, "journal.jsonl");
      if (!fs.existsSync(journalPath)) continue;

      try {
        const st = await fs.promises.stat(journalPath);
        const brief = await getFirstWorkDirFromDoJournal(journalPath);
        sessions.push({
          id: e.name,
          workDir: brief ? `[Do] ${path.basename(brief)}` : `${labelPrefix}${e.name}`,
          updatedAt: st.mtimeMs || st.mtime.getTime(),
          contextFile: journalPath,
          brief: brief || DEFAULT_FALLBACK_TITLE,
          isThinking: false,
        });
      } catch {
        // skip corrupted sessions
      }
    }
  }

  // 1. Scan old global path (legacy sessions from before Phase 09)
  await scanDir(getDoSessionsDir(), "[Do Legacy] ");

  // 2. Scan new workspace-local paths for each registered work dir
  for (const wd of registeredWorkDirs) {
    const wdDir = getWorkspaceDoDir(wd);
    await scanDir(wdDir, `[Do ${path.basename(wd)}] `);
  }

  return sessions.sort((a, b) => b.updatedAt - a.updatedAt);
}
```

### Change 4: Add `getFirstWorkDirFromDoJournal()` helper

Insert after `getFirstUserMessageFromThinkFile()` (after line 56):

```typescript
async function getFirstWorkDirFromDoJournal(journalPath: string): Promise<string | null> {
  try {
    const content = await fs.promises.readFile(journalPath, "utf-8");
    const firstLine = content.split("\n").find(l => l.trim().length > 0);
    if (!firstLine) return null;
    const entry = JSON.parse(firstLine);
    // Do session journal entries have a `work_dir` field in the session_start event
    if (entry.type === "session_start" && entry.work_dir) {
      return entry.work_dir;
    }
    // Fallback: extract work_dir from metadata
    return entry.work_dir || entry.metadata?.work_dir || null;
  } catch {
    return null;
  }
}
```

## Edge Cases

| Edge Case | Mitigation |
|---|---|
| `journal.jsonl` is empty | Skip silently (caught by try/catch in `scanDir`) |
| `journal.jsonl` lacks `session_start` | Return `null` from `getFirstWorkDirFromDoJournal`, use fallback title |
| `journal.jsonl` is corrupted JSON | Caught by try/catch, skip that session |
| Do session directory exists but no `journal.jsonl` | Checked via `fs.existsSync(journalPath)` |
| UUID collision between old and new paths | Deduplicated via `seen` set — first encounter wins |
| Multiple work dirs with same Do session UUID | `seen` set prevents duplicates |
| No `.consilium/sessions/` dir exists | `fs.existsSync` check returns early |
| Windows MAX_PATH issues | Phase 09 already added `ensure_safe_path()` in the Python CLI, but the extension runs on Node.js which handles long paths natively on modern Windows with `\\?\` prefix |
