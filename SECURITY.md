# Security Policy

## Supported Versions

Currently, Consilium CLI only provides security support for the latest version.

## Reporting a Vulnerability

Please report a vulnerability via the [MoonshotAI/consilium - Security](https://github.com/MoonshotAI/consilium/security) page, or open an [issue](https://github.com/MoonshotAI/consilium/issues) if it can be published publicly.
